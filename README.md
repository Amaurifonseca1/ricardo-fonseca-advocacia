# Ricardo Fonseca Advocacia

Site institucional da Ricardo Fonseca Advocacia e Consultoria, com foco em Direito Previdenciário em Maceió/AL.

## Tecnologias

- Next.js / Vinext
- React e TypeScript
- Tailwind CSS

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Compilação

```bash
npm run build
```

O conteúdo do site é informativo e não constitui promessa de resultado.
